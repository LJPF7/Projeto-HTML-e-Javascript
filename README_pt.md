## Sobre o projeto

Este projeto consiste no desenvolvimento de uma página WEB Lista de Tarefas utilizando **HTML**, **CSS** e **Javascript**.

---
## Objetivos

- Consolidar conhecimentos em programação com HTML, CSS e Javascript
- Explorar o desenvolvimento de páginas com o uso do Bootstrap
- Aplicar conceitos de programação com Javascript
- Consolidar conhecimentos DOM

---
## Funcionalidades

- Manipulação DOM
- Design responsivo
- Feedback visual com o uso de Modais, Tabs, Toasts e Navbar do Bootstrap
- Navegação inteligente com o uso de Navbar OffCanvas do Bootstrap

---
## Tecnologias utilizadas

- HTML 5.0
- CSS
- Javascript
